# 非洲大草原动画界面需求文档

## 一、整体概述

设计一个具有动画风格的非洲大草原交互界面，画面中包含丰富的自然背景与多种野生动物，动物在场景中持续运动，并真实模拟草原上的捕猎与迁徙行为。

---

## 二、背景场景设计

采用卡通/动画插画风格（类似迪士尼《狮子王》的视觉风格），背景为静态或缓慢视差滚动的大草原全景图，包含以下元素：

| 场景元素 | 说明 |
|--------|------|
| 草地 | 前景为大片绿色草地，可有风吹草动的轻微动效 |
| 湖泊/水潭 | 中景有一处静态湖泊，水面有轻微波纹动效 |
| 河流 | 画面一侧有蜿蜒河流，水流方向有流动动效 |
| 远景地平线 | 远处呈现非洲特有的平顶金合欢树剪影 |
| 天空 | 背景上方为蓝天，有白云缓慢飘移的动效 |

---

## 三、动物角色设计

### 3.1 动物种类

场景中包含以下动物，均采用与背景一致的卡通插画风格：

**食草动物（被追逐方）：**
- 斑马（Zebra）
- 非洲水牛（Buffalo）🐃
- 羚羊（Antelope）
- 角马（Wildebeest）

**大型温和动物（自由漫步，不参与捕猎）：**
- 非洲象（Elephant）🐘
- 长颈鹿（Giraffe）

**肉食动物（追逐方）：**
- 狮子（Lion）🦁
- 鬣狗（Hyena）

### 3.2 动物数量建议

| 动物 | 建议数量 |
|------|---------|
| 斑马 | 3–5 只，成群移动 |
| 角马 / 水牛 | 2–4 只 |
| 羚羊 | 3–6 只，速度最快 |
| 大象 | 1–2 只 |
| 长颈鹿 | 1–2 只 |
| 狮子 | 1–2 只 |
| 鬣狗 | 1–2 只 |

---

## 四、动物行为与动画逻辑

### 4.1 自由迁徙行为（所有动物）

- 所有动物在背景画布范围内**持续移动**，不会静止超过 3 秒。
- 移动路径为带有随机偏移的平滑曲线（非直线），模拟自然漫步感。
- 到达画面边缘时，动物从对侧重新出现（循环场景）或转向返回。
- 大象和长颈鹿移动缓慢，步伐沉稳；羚羊移动速度最快，步伐轻盈。

### 4.2 捕猎追逐行为（肉食动物 vs 食草动物）

**触发条件：**
当狮子或鬣狗与某只食草动物（斑马/角马/水牛）的距离小于设定阈值时，触发追逐模式。

**追逐逻辑：**
1. **肉食动物**：锁定目标，加速向目标方向移动，速度明显提升。
2. **目标食草动物**：检测到威胁后，以更快速度逃离（方向为远离肉食动物）。
3. **附近同类**：目标周围的其他食草动物同步受惊，开始向四散逃跑（群体惊逃效果）。

**结束条件：**
- 追逐持续一段时间后（如 8–12 秒），肉食动物减速，双方恢复正常游荡状态。
- 或：捕猎者追上目标后播放一段简短动画（可简化为目标短暂消失后再出现在远处）。

### 4.3 动物朝向与动画帧

- 动物图像根据移动方向**自动水平翻转**，确保始终面朝运动方向。
- 每种动物有**行走**和**奔跑**两套帧动画，分别对应普通移动和追逐/逃跑状态。

## 五、画面层次结构（由后至前）

```
[第1层] 天空 + 白云（缓慢移动）
[第2层] 远景地平线 + 金合欢树剪影（视差缓慢移动）
[第3层] 中景：湖泊 + 河流（轻微水波动效）
[第4层] 近景草地（可有风吹效果）
[第5层] 动物层（所有动物在此层运动）
[第6层] 前景草丛/植被遮挡（增强空间纵深感）
```

## 六、技术实现建议

| 项目 | 建议方案 |
|------|---------|
| 实现方式 | HTML5 Canvas 或 CSS + JavaScript 动画 |
| 动物素材 | SVG 矢量图或 Sprite Sheet 帧动画 |
| 运动算法 | 使用**转向行为（Steering Behavior）**模拟自然运动，包含"漫步"、"追逐"、"逃跑"三种状态 |
| 性能优化 | 动物数量控制在 15 只以内；离屏动物暂停渲染 |
| 响应式 | 画面按比例缩放以适配不同屏幕尺寸 |

---

## 七、可选扩展功能

- 🔊 **音效**：背景鸟鸣、风声；追逐时加入急促音效
- 🕐 **昼夜切换**：画面随时间从白天渐变为黄昏（橙红色天空）
- 🖱️ **交互**：鼠标悬停在动物上显示动物名称；点击可查看动物介绍
- 📷 **镜头跟随**：点击某只动物后，视角跟随该动物移动
